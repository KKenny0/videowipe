# 短片试擦里程碑

日期：2026-09-08。用户已授权方案完成后直接实施。

## 目标与验收

在全片修复前，用当前目标与掩码试擦 3 或 5 秒（片尾自动缩短），播放上下排列的原片/结果对比。修改目标、框或区间即隐藏旧结果。试擦失败保留审阅状态，可重试；成功不自动执行全片。

验收：非分段边界区间沿用全片 STTN 分段上下文及全局帧掩码；只输出请求帧；原音轨按同一区间截取，无音轨也成功。空选择、非法框、非有限时间、越界时间、并发请求均拒绝。刷新可恢复试擦状态。正常全片流程不变。

## 最小实施路径

Web → 同一任务/审阅校验 → WipeEngine → STTN → FFmpeg 对比 MP4

1. `WipeRequest.trial_range` 增加可选半开帧区间，通过 engine / DetextTask / InpaintJob 传给 STTN。只支持内置 STTN；其他模型明确拒绝，避免默默处理全片。试擦保留全片 mask、全局帧号与 gap 分段，不重新检测、不裁剪重编码源视频。区间两端按 gap 扩展推理，只编码选中帧；试擦输出原片在上、结果在下。
2. Web 新增 POST `/jobs/{id}/trial` 和 GET `/jobs/{id}/trial-video`，复用 confirm 的校验函数。每次试擦独立目录与计划副本；不改正式计划。新增 `trial_running` 状态，成功/失败均回到 `preview_ready`，保留单任务槽。结果附带原请求供界面判断是否过期；视频 URL 绑定本次试擦 ID，支持原生 Range 播放。
3. 现有页面新增起始秒数、3/5 秒选择与试擦按钮，复用进度与恢复流程，原生 video 控件播放。正式处理期间禁用编辑；试擦期间冻结选项，完成后解冻。
4. 用已有三条多语素材及 golden mask 生成固定试擦样片、代表帧与运行记录；这些是修复输出检查，不是自动检测质量证明。另以可控视频覆盖非整段边界、时间掩码、音频偏移、片尾和全片/试擦一致性。已有基准负责检测质量，不增加新平台。

共 14 个源码/测试/文档文件（含本方案与中英文 README），无新服务、模型、依赖、环境变量、CLI 命令或 WipePlan schema。作为一个可用切片交付，无发布或提交操作。

## 风险与边界

关键假设：当前 STTN 各 gap 分段独立推理；若以后改为跨段状态，必须同步修改试擦上下文并重验一致性。编码不同导致轻微像素差异，不能承诺压缩后逐像素相等。OpenCV/现有引擎按恒定帧率处理；不扩展为可变帧率编辑器。试擦只代表选中区间，不代表全片质量。外部模型、自动挑片段、AI 自检、局部结果拼接、任务持久化不在本次范围。
