# Issue tracker: GitHub

Specs and tickets live in KKenny0/videowipe GitHub Issues.
Use gh for tracker operations and --body-file for multiline bodies.
Publishing means creating an issue; reading includes its comments.

Apply ready-for-agent to approved specs and tickets.
Create tickets in dependency order and use native blocking links.
If native dependencies are unavailable, record Blocked by issue references.
Do not close or modify parent issues unless explicitly requested.

PRs as a request surface: no.
