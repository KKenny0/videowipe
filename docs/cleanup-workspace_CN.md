# 清理工作区详细说明

[返回 README](../README_CN.md)

选片后立即播放本地原片。候选出现后，右侧目标卡片即可显示它实际出现的画面和时间；未勾选的目标也能定位查看。
网页自动从已选目标的最长连续出现区间推荐有效的 3 秒试擦，片头没有字幕时无需手动寻找起点。
也可指定 3/5 秒或直接处理全片；不足 3 秒及片尾区间自动缩短。

试擦在同一视频中上下同步显示原片和清理结果，保留该片段的声音。
修改目标、区域框或时间后，旧试擦失效；失败可直接重试，不必重新上传。
满意后手动启动全片，完成后原地播放，并回到最近试擦位置。
暂停时可切换原片/结果；下载名保留原文件名并加 `_clean.mp4`，每次全片处理写入独立目录。

页面支持窄屏、键盘微调和明暗配色。时间细化期间即可修改目标和区域框，操作结束自动保存；细化完成后才可试擦或处理全片。
刷新或重启服务后，会校验源片及产物并恢复最后一个已保存任务；中断的计算需手动重试，不会自动接着推理。
取消会等待后台计算退出再释放任务槽；关闭标签页不会取消处理。进度显示实际阶段和处理数量，积累足够的可比处理记录后才显示剩余时间范围，并显示实际加载的设备。

相同设置的试擦会复用已校验结果，每个任务最多缓存三条、128 MiB；执行因素变化后重新计算，正在播放的结果不参与淘汰。
多标签页通过版本校验避免覆盖彼此的修改。
浏览器不支持源编码时，仍可检测并通过目标对应帧查看，不会自动转码原片。
当前验收范围是恒定帧率 SDR 视频；HDR 或可能不恒定的帧率会提示需留意。
一段满意的试擦不代表全片质量，下载前仍应播放检查。

成片下方按首次/末次生效边界、人工标记及能定位到帧的警告提供复查窗口；默认最多 12 项，可逐目标展开全部边界并循环播放。它们是导航建议，不是自动质量判定。“看过了”和问题标记绑定当前结果；重新导出后只保留执行身份、裁剪带和该帧 alpha 均未变化的问题标记。

可修改目标的生效时间，或拖出矩形“保护这里”，也可用坐标与时间输入完成。时间按半开帧区间保存，开始向下取整、结束向上取整；区间会排序合并。每次修改可撤销。“实际处理范围”显示服务端生成的当前帧 alpha，包含羽化与保护；保护像素在编码前与原片完全一致。视频重新编码仍可能改变压缩后的像素。

balanced/sensitive 规划复用逐帧检测，让字幕范围随当前文字变化，并在前后各 0.25 秒内稳定字高，不跨越字幕空档。fast 模式和仅由 band fallback 定位的候选仍保留静态蒙版。此类计划使用 v3，每条字幕轨迹仍是一个可复查目标。旧 v1/v2 计划保持原语义；静态保护计划仍用 v2，其余静态计划用 v1。修改时间只裁切已有局部证据，不会在无字幕帧凭空生成蒙版；手工框选会替换该目标的自动局部范围。保存前会补检时间插值产生的未观测边界帧，已确认空帧或检测失败帧仍保持原图。保存后无需重新检测即可重放；旧应用会拒绝 v3，而不会把它压平成整片蒙版。保护优先于移除，keep 只表示不主动移除该候选。外部模型/ProPainter 明确拒绝保护计划；不能丢弃保护后执行。基础检测计划、审阅版本与每次成片分别保留，修改后需重新试擦或导出。

网页默认启用任务内预测复用；三样片三轮性能与像素等价门槛通过。该验收不代表自动检测或修复画质已达标。

SDK 可显式设置 `WipeRequest(prediction_cache_dir=..., ...)` 复用 STTN 分段预测，默认关闭。缓存不保存成片；每次从原片解码、重新合成并编码。源片、裁剪带、全局帧段、权重、设备/精度或实现变化都会重新推理。单目录最多 512 MiB；同一任务根目录下的同名缓存目录合计最多 2 GiB，满额停止写入，损坏项重新计算。SDK 调用方应使用统一的 `任务根目录/任务ID/predictions` 布局以共享总额度。Web 不接受缓存路径；页面可清除本任务的预测缓存。

试擦沿用内置 STTN 的全片上下文与掩码。SDK 可通过 `WipeRequest(trial_range=(start_frame, end_frame), ...)` 生成同样的对比视频，
区间为半开区间 `[start_frame, end_frame)`；`preview=True` 仍然只生成检测计划，不能与试擦同时使用。
